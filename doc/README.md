# Documentation

The custom skins use opaque RGB palette colors. Controls with optional backgrounds
expose their parent when the state’s `HideBackground` flag is set. Win11Skin also provides
`HideBorder` for filled controls without an outline. These flags replace the
former `Transparent` color (`Clear` in UbuntuSkin).
