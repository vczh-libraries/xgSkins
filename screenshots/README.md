# Screenshots

## UbuntuSkin References

`UbuntuReference` stores screenshots of the latest Ubuntu LTS trash bin and settings apps, it could represent Ubuntu's design.

`LibreOfficeReference` demos how `LibreOffice` handle menu and toolbar.

Their text size does not matter, you should stick to GacUI's provided text size, and you should basically keep the current sizing and margin so that the reworked UbuntuSkin does not change control default sizes too much.

`UbuntuReference`'s menu has a small triangle, we won't have that, keep the menu in its current basic shape.

I would prefer rectangle over roundrect, `LibreOfficeReference` has a lot of roundrect samples, but you should keep things in rectangle.

The references here are for color references, and some art design hints. `LibreOfficeReference`'s combo box has a very big square dropdown button, I don't like that, keep the current small design in terms of sizing.

Ribbon is not included, but basically it should looks like toolbar with larger buttons. We keep tab headers horizontal, the vertical tab is for color design only.

There are radio button but no check box references, check box should still be a square with a tick but in the same color.
